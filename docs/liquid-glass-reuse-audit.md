# 液态玻璃复用评估（2026-09-05）

## 基线与结论

依赖基线为 `gradle/libs.versions.toml` 的 Miuix `0.9.4-4f86de92-SNAPSHOT`。
交互参考本地 Miuix checkout `b09d5deb` 的
`example/shared/src/commonMain/kotlin/component/liquid/LiquidGlassNavigationBar.kt`
与 `component/animation/DampedDragAnimation.kt`；后者最近修改为 `6cef2957`。
参考仓库：https://github.com/compose-miuix-ui/miuix 。示例基线与依赖版本并不等同。

项目复用了 Miuix Backdrop/blur 基础设施，并移植、适配了示例的透镜和交互。
这不是直接调用一个完整上游导航组件，因此不以百分比宣称“完整复用”。

## 能力对照

| 层 | 已有能力 | 本次处理与边界 |
| --- | --- | --- |
| 背景效果 | Miuix Backdrop、blur；本地 Lens、Vibrancy、CombinedBackdrop、InnerShadow | 保留底栏组合捕获与背景自采样保护，无依赖升级 |
| 交互 | 按压弹簧、移动、拖动、Pager 跟随、高光 | 修复 press/release 共用任务导致点按放大被取消；释放在接近目标且按压完成后回缩 |
| 本地适配 | 同步拖动目标、最新任务优先、Pager 所有权、搜索宽度补偿 | 保留，不能直接用上游示例覆盖这些逻辑 |
| 形状 | 胶囊形状、底栏指示器几何 | 上游也用 CircleShape；扁平感取决于宽高比。非底栏接入已有 1.6 比例策略，底栏规则不变 |
| 内容 | 底栏选中内容捕获、横向形变补偿 | 分段控件恢复相同捕获链路，文字和图标参与透镜与色散；捕获内容按壳层内容高度测量，图标切换开关透传 |
| 语义与触控 | 主内容提供 Tab 语义；装饰层清除语义 | 保留调用方视觉高度，固定槽宽下限 48dp；Compose 可点击节点的触控扩展及父级约束仍需设备检查 |

根据实际反馈，独立前景使文字和图标绕过色散，不满足底栏效果对齐要求，已撤销。
分段控件与底栏现在都采集选中内容，再通过组合背景执行透镜、色散与横向形变补偿。
非底栏仍保留 1.6 宽高比；捕获内容高度独立于透镜高度，避免通过缩小测量高度挤压文字。
大字体、图文双行在透镜边界的裁切仍需设备验证。

评论排序控件原本请求 40dp 壳高、30dp 指示器高。上一轮强制将壳高提高到 48dp，
改变了标题行的测量与中心位置；已恢复调用方视觉高度，不通过统一增高壳层扩充触控区域。

## 封装参数消费（已补齐）

对齐基准为首页底栏共用的 `FloatingBottomBar` 渲染实现。默认参数为水平/垂直内边距
4dp、点按折射开启、闲置指示器颜色不覆盖；不为分段控件复制一套材质常量或弹簧。

| 参数 | 实际消费与默认行为 |
| --- | --- |
| `tapPressRefractionEnabled` | 入口、包装、共用渲染器全链路透传。默认采用底栏按压进度驱动透镜；false 只关闭点按引起的指示器折射，保留缩放、高光和拖动/Pager 折射 |
| `indicatorIdleSurfaceColorOverride` | 玻璃路径覆盖闲置表面颜色，仍按底栏的 `1 - pressProgress` 淡出；无玻璃路径覆盖选中背景。不传值时分别沿用底栏深浅色闲置表面与普通选中色 |
| `containerHorizontalPadding` | 外部宽度、受约束后的实际槽宽、指示器偏移、捕获/前景内容和 LTR/RTL 手势命中使用同一个值；不再固定减去 8dp。负值归零 |
| `containerVerticalPadding` | 消费到共用壳层内容与分段捕获内容高度，范围为 0 到壳高的一半；不把文字压缩成扁平指示器的高度 |
| `liquidGlassTuningOverride` / 颜色覆盖 | 继续通过共用渲染器消费。未覆盖时使用存储的玻璃强度、进阶设置与可读性策略 |

`allowNativeLabelOverflow`、`preferInlineContentStyle`、`forceEqualWidth` 是原生布局/样式选择契约，
不是玻璃材质参数；浮动分段路径本身采用等宽槽位。`enabled` 与拖动开关仍控制选择回调及手势。
首页顶部直接使用包装层时也采用相同默认值。

保留非底栏 1.6 几何，材质、交互、内容捕获与色散共用底栏实现；实际尺寸不同，不能宣称逐像素相同。
缺少完整的图形效果、字体放大和跨设备回归证据；源码接线不能替代渲染验证。

不要一次性移植上游全部示例，也不要把底栏与分段控件的内容几何强制统一。
性能优化优先保持绘制阶段读取动画值、复用外部背景源及避免重复捕获；进一步性能结论需真实设备数据。

## 完整移植上游全部液态示例的可行性

范围指 Miuix 示例中的液态导航及其依赖，不指整个示例应用中的对话框、颜色选择器等无关组件。
本地示例目录包含 LiquidGlassNavigationBar、Lens、Vibrancy、CombinedBackdrop、InnerShadow，
交互依赖 DampedDragAnimation 和 InteractiveHighlight；导航示例注明源自 AndroidLiquidGlass（Apache 2.0）。
项目已具有这些对应能力，继续完整对照其效果链在技术上可行。

不建议原样覆盖生产组件，原因是上游是展示示例，本项目多出了以下必须保留的契约：

- 外部 Pager 位置/滚动所有权、快速反向切换、搜索改变槽宽但不重建手势所有者。
- 图标与文字组合、皮肤、徽标、RTL、边缘返回手势及禁用状态。
- 可读性设置、平台/API 降级、外部背景源复用和避免 RenderNode 自采样。
- 40dp 评论排序、动态分页、顶部分类、底栏等不同几何与宿主约束。

建议采用“固定上游版本的参考实现＋逐项行为对照”，而非直接替换：
先在隔离预览/测试入口保留完整示例及许可证来源，再逐项比较静止、按压、拖动、释放、
色散与高光；确认差异后只合入必要效果逻辑，保留上述生产契约。
完整示例复制本身成本有限，主要成本在多场景交互兼容、不同 Android 渲染后端和性能验证。
没有编译及设备结果前，不承诺无回归、帧率收益或确定工期。

本轮仅评估完整移植，未导入全部示例或新增依赖。

## 本次验证边界

所有可用的多项复用 Dock 统一开启直接拖动，包括搜索排序、番剧播放页、首页子分类、
五项以上的空间/插件栏。共用包装不再允许页面通过旧 `dragSelectionEnabled` 参数关闭拖动；
参数保留源码兼容，实际由 `enabled && itemCount > 1` 决定。禁用态及单项控件除外。

长 Dock 的滚动视口现在使用共用 `liquidDockViewport`：固定圆角细边框加横向裁切，
边框位于滚动层外，搜索排序、共用分页栏和个人空间次级栏的左右端始终有可见轮廓。
内部材质、内容和指示器继续滚动；不会以初始滚动偏移、额外空白标签或缩小文字伪造边缘。
尚需设备验证首屏、滚动中间、左右端点、深浅色及指示器边缘拖动。
截图反馈表明此前胶囊裁切将超出外壳的按压放大切掉，现为上下各保留 30dp 绘制余量，
不改变测量尺寸、边框位置或按压倍率。横向仍裁切于视口，避免滚动内容越界。

首页顶部三种模式（图标＋文字、仅图标、仅文字）及动态顶部导航使用 TopNavigation
几何：最低宽高比 1.35、目标上下留白 2dp，让窄槽的指示器更饱满；普通分段控件仍为 1.6。
三种首页模式沿用各自槽宽策略，不统一放大外壳或文字。捕获范围、指示器高度、按压几何
都消费同一个模式，滑动色散与直接拖动逻辑不变。新增真实首页宽度策略的三模式断言，未运行。

复用指示器的静止留白统一为上下各 2dp：给定壳高时，分段路径以壳高减 4dp 为
目标指示器高度，再由实际槽宽 / 1.6 限制，窄槽优先保留扁平比例。
例如 40dp 壳高、66dp 槽宽由 30dp 指示器调整为 36dp；底栏自身及外壳位置不变。
`indicatorHeight` 在分段模式下作为未提供壳高时的回退和零高度禁用输入，
正常渲染由统一留白策略决定，避免各调用者旧高度再次产生不同间距。
捕获范围与按压几何使用同一最终高度；新增常规留白、窄槽比例与底栏不变断言，未执行测试。

手势入口已统一为直接拖动选中指示器：可滚动的通用分页栏、个人空间次级栏不再
要求长按；旧 `longPressDragSelectionEnabled` 参数作为兼容拖动开关，在共用渲染器
也走直接拖动。禁用态与单项限制不变，未选中槽位仍可用于横向滚动。
需设备验证滚动父容器与指示器手势仲裁、轨道边缘跟随及取消；本轮未执行设备操作。

拖动手感补充核对：底栏与分段路径均使用 SPRING 跟随、相同位置/缩放弹簧、
同一拖动结束结算与 Pager 所有权逻辑。发现速度除以 selectable range、外壳偏移除以
完整控件宽度会让短控件更敏感，已改为五项首页底栏参考（速度除以 4、偏移参考宽度为
五个实际槽宽加左右内边距）。五项底栏基线不变；两项/三项及自定义数量底栏不再按数量放大。
不同槽宽和指示器形状仍按现有几何适配，不能据此宣称不同尺寸逐像素相同或已实机验证手感。

新增可控 Compose 帧时钟测试，覆盖点按放大及复原、快速反向切换与拖动释放、单项同目标释放；
新增分段指示器比例与首尾边界测试，并保留底栏默认几何断言。
参数补齐新增点按折射开关/拖动/Pager 组合、非默认内边距槽位与首尾对齐测试，以及透传集成断言。
这些测试尚未执行：用户要求本轮不编译、不运行 Gradle 测试、不打包。
本轮仅进行差异和源码静态检查，未进行设备验收。

后续授权后的设备验收：动态分页、视频详情分页与评论排序、首页顶部和底栏；
手机/平板、深浅色、字体放大、图文模式、玻璃/图标动画/搜索开关；
连续点按、滑动中点按、拖动取消、返回页面和前后台恢复。检查缩放复原、文字无裁切、
指示器不越界及不重复提交选择。
